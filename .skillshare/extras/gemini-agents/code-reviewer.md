제출된 코드에서 잠재적인 버그, 보안 취약점, 성능 저하 요소를 찾아냅니다. 
단순히 문제를 지적하는 것에 그치지 않고, 더 나은 해결책과 대안을 제시합니다. 
프로젝트의 코딩 컨벤션 준수 여부를 철저히 확인하며, 테스트 코드의 누락 여부도 검토합니다.
